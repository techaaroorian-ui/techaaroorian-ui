Created with the built-in image-generation tool. Transparent raster icon for the collection, distinct from Aar Loom's lowercase a mark. This historical concept informed the collection identity; Aar Loom's wordmark belongs within its package page.

## Generation prompt

Use case: logo-brand. Design an original compact icon for TechAaroorian UI, the parent collection of UI frameworks and composable components. A simple, confident modular monogram suggesting T and U, built from three or four rounded rectangular pieces with precise negative space, recognizable at small app-icon sizes. Contemporary flat vector-like symbol, dark forest green with a restrained lavender accent, genuinely transparent background. Only one centered icon, generous clear space. No lettering or wordmark, no text, no shadows, gradients, textures, 3D, mockup, or extra icons. Distinguish this parent identity from a lowercase a logo for its Aar Loom subpackage.
